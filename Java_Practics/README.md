## Реализованные задания

### Задание 1. Методы
- `fraction(double x)` — возвращает дробную часть числа.
- `isPositive(int x)` — проверяет, является ли число положительным.
- `is2Digits(int x)` — проверяет, является ли число двузначным.
- `isDivisor(int a, int b)` — проверяет, делит ли одно число другое нацело.
- `isEqual(int a, int b, int c)` — проверяет равенство трёх чисел.

### Задание 2. Условия
- `is35(int x)` — проверяет делимость на 3 или 5, но не на 15.
- `max3(int x, int y, int z)` — возвращает максимальное из трёх чисел.
- `sum2(int x, int y)` — возвращает сумму, но если она в диапазоне 10–19, возвращает 20.
- `age(int x)` — возвращает корректную форму слова «год/года/лет» для возраста.
- `printDays(String x)` — выводит день недели и все последующие (switch без break, кроме последнего).

### Задание 3. Циклы
- `reverseListNums(int x)` — выводит числа от x до 0 в обратном порядке.
- `pow(int x, int y)` — возводит число x в степень y без использования `Math.pow`.
- `equalNum(int x)` — проверяет, все ли цифры числа одинаковы.
- `rightTriangle(int x)` — рисует прямоугольный треугольник из звёздочек.
- `guessGame()` — игра «Угадай число» с проверкой ввода.

### Задание 4. Массивы
- `findFirst(int[] arr, int x)` — индекс первого вхождения элемента x.
- `findLast(int[] arr, int x)` — индекс последнего вхождения элемента x.
- `reverseBack(int[] arr)` — возвращает новый массив в обратном порядке.
- `concat(int[] arr1, int[] arr2)` — объединяет два массива в один.
- `deleteNegative(int[] arr)` — удаляет все отрицательные элементы.
